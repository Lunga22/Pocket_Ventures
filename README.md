# PocketVentures POS SaaS

An offline-first, local-first Point of Sale (POS) and inventory management web application built for seamless business tracking inside Google Chrome.

## 🚀 Features

* **Offline-First Architecture:** Powered by browser-native IndexedDB for instant, reliable local data storage without requiring an external server setup.
* **Inventory Management:** Add, track, and manage stock items with clean form validation and real-time 4-column table rendering.
* **Pinned Navigation:** Features a fixed viewport header to keep core navigation controls accessible at all times during scrolling.
* **PWA Ready:** Fully installable as a Progressive Web App on desktop or mobile devices with custom app icons and manifest configuration.

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
* **Database:** Browser-native IndexedDB
* **PWA:** Web App Manifest, Service Worker support
